Для владельца сайта

Настройка Supabase, модерации и AI

Публичный сайт читает только одобренные материалы. Новые заявки проходят через Edge Function, а права владельца проверяются сервером по UUID пользователя Supabase Auth.

Секретные ключи не попадают в браузер
1

Выполни SQL-миграцию

Открой SQL Editor и выполни целиком docs/supabase-schema.sql. Скрипт создаёт RLS, таблицу администраторов, публичное представление и серверный rate limit.

2

Создай владельца

В Authentication → Users создай пользователя. Затем добавь его UUID в public.site_admins командой из комментария в конце SQL-файла.

3

Проверь публичный конфиг

В docs/js/submission-config.js должны быть только Project URL и publishable key. Не добавляй туда OpenAI key, Supabase secret key или email администратора.

4

Разверни две Edge Functions

Выполни supabase functions deploy. Функция submit-content принимает и ограничивает заявки, а ai-assistant безопасно обращается к OpenAI.

Как работает безопасность

Анонимный браузер не имеет прямого INSERT в submissions. Просматривать очередь, менять статус и удалять заявки может только авторизованный пользователь, для которого is_site_admin() возвращает true.
